```

- 相談しやすさを最優先

  背景：#C86B3C・白テキスト・角丸10px・中央寄せ

- 入力欄：白背景・角丸8px・--color-borderで薄いボーダー
- ラベル：フィールド上部・Noto Sans JP・小さめ

「内容を確認の上、3営業日以内にご返信いたします。
お急ぎの場合はInstagramのDMよりご連絡ください。」

【Google Form連携】
action属性は後から差し替え可能な形で実装：
```

## 実装時の注意事項

```
【DESIGN.mdへの準拠】
- カラーはデザイントークンの変数のみ使用
- 指定されていない装飾は追加しない
- 強い原色・テック感のあるデザインは禁止
- ボタンは1画面に1つのメインCTAのみ

【レスポンシブ】
- スマホファースト
- ブレークポイント：768px
- スマホ：1カラム・padding 24px
- タップターゲット：最小44px

【フォント読み込み】
<link href="https://fonts.googleapis.com/css2?
  family=Noto+Sans+JP:wght@400;500&
  family=Noto+Serif+JP:wght@400;600&
  display=swap" rel="stylesheet">

【パフォーマンス】
- 画像はWebP推奨・できるだけ圧縮
- Google Fontsはdisplay=swap使用

【アクセシビリティ】
- 画像にalt属性必須
- ボタン・リンクに意味のあるテキスト
- カラーコントラストは読みやすさを確保
```
