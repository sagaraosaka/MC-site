## 1. TOPページ（index.html）

### 役割
- 世界観・雰囲気を伝える
- 各ページへの自然な導線をつくる
- 初めて訪れた人が「信頼できる」と感じる

### セクション構成

```
1. Hero
2. KEY PRODUCEとは
3. 選ばれる理由（3つ）
4. サービス概要
5. 実績ギャラリー
6. プロフィール導線
7. CTA
```

### セクション詳細

#### 1. Hero
| 項目 | 内容 |
|---|---|
| メインコピー | 「このまちだから、盛り上がる。」 |

| CTAボタン | 「サービスを見る」→ /service/ |

| 項目 | 内容 |
|---|---|
| 内容 | サービスの一言紹介 |

#### 3. 選ばれる理由（3つ）
| # | タイトル | 説明 |
|---|---|---|
| 1 | 地域密着の空気感 | 和歌山のまちを知っているからこそ、場の雰囲気をつかむことができる |
| 2 | 「入る場」をつくる盛り上げ方 | 参加しやすい声掛けと流れで、見ているだけの場を参加したくなる場へ |

#### 4. サービス概要

#### 5. 実績ギャラリー

| リンク | Phase2以降に /works/ へ誘導 |

#### 6. プロフィール導線

## 4. お問い合わせページ（/contact/index.html）

### 役割
- 問い合わせのハードルを下げる
- シンプルで迷わないフォーム

### セクション構成

```
1. ページタイトル・リード文
2. お問い合わせフォーム
3. 返信についての補足
```

### フォーム項目

| 項目 | 種別 | 必須 |
|---|---|---|
| お名前 | テキスト | ✅ |
| メールアドレス | メール | ✅ |
| イベントの種別 | セレクト（企業・地域・婚礼・その他） | ✅ |
| お問い合わせ内容 | テキストエリア | ✅ |

> **実装方針**：静的サイトのためFormspreeまたはNetlify Formsなどの外部フォームサービスを使用推奨

### 補足テキスト（仮）
「内容を確認の上、〇営業日以内にご返信いたします。お急ぎの場合はInstagramのDMよりご連絡ください。」
