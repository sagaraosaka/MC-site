## 1. 仕様整理メモ

### サービス概要

| 項目 | 内容 |
|---|---|
| サービス名 | KEY PRODUCE（キー・プロデュース） |
| 副題 | 紀州のイベントをつくる |
| 拠点 | 和歌山市を中心とした地域密着型 |
| 現在の事業 | イベントMC・司会 |
| 将来の方向 | イベント企画・運営全般へ拡張 |

---

### サイトの役割

> 「紹介された人が、価格・雰囲気を確認して、納得して問い合わせをする場所」

- 紹介ベースで知った見込み客がサイトを訪問
- サービス内容と料金感を確認
- 安心・納得した上で問い合わせへ
- サイトは「商談前のショールーム」として機能する

---

### ターゲット

| 優先度 | ターゲット |
|---|---|
| 🔴 メイン | 企業のイベント担当者 |
| 🔴 メイン | 地域イベントの主催者 |

---

### デザイン方針

- 落ち着いた・大人向け・派手すぎない
- 余白を活かす
- 写真・雰囲気を邪魔しないUI
- 押し付けない導線
- 静的サイト（HTML / CSS / JS）ベース

---

### サービス設計

| プラン | 内容 | 状態 |
|---|---|---|
| MCプラン | 司会・進行に特化 | ✅ 対応中 |
| プロデュースプラン | イベント企画・運営サポート込み | 🔜 Coming Soon |

**MCプランに含まれるもの**

- 事前打ち合わせ

企業イベント・式典 / 地域祭り・野外イベント / 婚礼・パーティー / その他（スポーツ・マルシェ等）

**料金目安**

3万円〜（税別・内容により変動）

## 2. サイト構成案

```

├── service/

│   └── index.html      # プロフィール

│   └── index.html      # お問い合わせ
```

### 共通コンポーネント

以下はすべてのページで使い回す共通パーツとして実装する。

| コンポーネント | 内容 |
|---|---|
| Header | ロゴ（KEY PRODUCE）＋ グローバルナビ |
| Footer | コピーライト・SNSリンク等 |
| CTAセクション | 「まずはお気軽にご相談ください」ボタン |
| ナビゲーション | TOP / サービス・料金 / プロフィール / お問い合わせ |

> **設計ポイント**：CTAセクションは全ページ下部に配置。  
> 各ページを読み終えたタイミングで自然に問い合わせへ誘導する。
