## 指示③｜デザイン方針（全ページ共通）

```
以下のデザイン方針を全ページで統一してください。

【トーン】
- 落ち着いた・大人向け・派手すぎない
- 余白を広めに取る
- 写真・雰囲気を邪魔しないUI
- 押し付けない導線

【カラーパレット（案）】
- ベース：#FFFFFF（白）
- テキスト：#1a1a1a（ほぼ黒）
- アクセント：#8B6F47（落ち着いたブラウン系）※調整可
- サブ背景：#F7F5F2（オフホワイト）
- ボーダー：#E0DDD8

【フォント】
- 日本語：Noto Sans JP（Google Fonts）
- 英語：Cormorant Garamond または Playfair Display（上品な印象）
- 本文サイズ：16px
- 行間：1.8

【余白の基準】
- セクション間：80px〜120px
- コンテンツ幅：最大1000px・中央寄せ
- モバイル：padding 24px

【ボタンスタイル】
- アウトラインボタン推奨（塗りつぶしより押し付けがましくない）
- ホバー時：背景色がアクセントカラーに変化
```

## 指示⑦｜お問い合わせページの実装

```
/contact/index.html を新規作成してください。
フォームはFormspreeを使用します。
（action属性のURLは後から差し替え可能な形で実装）

【セクション構成】
1. ページタイトル・リード文
2. お問い合わせフォーム
3. 返信についての補足

【フォーム項目】
- お名前（テキスト・必須）
- メールアドレス（email・必須）
- イベントの種別（select・必須）
  選択肢：企業イベント・式典 / 地域祭り・野外イベント /
          婚礼・パーティー / その他
- お問い合わせ内容（textarea・必須・5行程度）
- 送信ボタン：「送信する」

【補足テキスト】
「内容を確認の上、3営業日以内にご返信いたします。
お急ぎの場合はInstagramのDMよりご連絡ください。」

【フォームのデザイン方針】
- ラベルはフィールドの上に配置
- 入力欄はシンプル・角丸・ボーダーのみ
- エラー表示はHTML標準のバリデーションで可
- 送信完了後のサンクスメッセージを表示
```

## 実装時の注意事項

```
【レスポンシブ対応】
- ブレークポイント：768px（スマホ／PC）
- スマホファースト推奨

【パフォーマンス】
- 画像はできるだけ圧縮（WebP推奨）
- Google Fontsはdisplayスワップを使用

【アクセシビリティ】
- 画像にはすべてalt属性を設定
- ボタン・リンクには意味のあるテキストを

【コード品質】
- CSSはstyle.css（共通）とcomponents.css（コンポーネント）に分離
- JSはmain.jsに集約
- コメントは日本語で記載
```
