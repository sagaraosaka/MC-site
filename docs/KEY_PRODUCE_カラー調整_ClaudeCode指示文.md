## 指示内容

css/style.cssのカラー変数（:root）を以下の内容に更新してください。
他の箇所は変更しないでください。

```css
:root {
  /* ベース */
  --color-bg:        #F5F0E8;  /* 少し黄みがかったベージュ（卒業・ムーンライズ寄り） */
  --color-bg-sub:    #EDE6D6;  /* セクション背景の切り替え用・少し深めのベージュ */
  --color-text:      #2A2520;  /* 少し茶みがかったほぼ黒（温かみのあるテキスト） */
  --color-text-sub:  #6B5F52;  /* サブテキスト・キャプション用 */

  /* アクセント */
  --color-accent:    #C07040;  /* テラコッタ寄りのオレンジ（ムーンライズ・マッドマックス） */
  --color-accent-dark: #9A5830; /* ホバー時・強調時 */
  --color-sub:       #5C7A5C;  /* 深みのあるグリーン（卒業・ムーンライズ寄り） */
  --color-sub-light: #8FA882;  /* CTAセクション背景・薄いグリーン */

  /* ボーダー・シャドウ */
  --color-border:    #D8CFBF;  /* 温かみのある薄いボーダー */
  --color-shadow:    rgba(42, 37, 32, 0.08); /* テキストカラーベースの影 */
  --color-white:     #FFFFFF;
}
```
